## Decisions

- Entities live in Core so Mapperly maps them directly; Data only configures them. The tsvector
  (`SearchVector`, English, title, summary and Markdown body) is a shadow generated column with a GIN index.
- Enums are stored as integers; JSON and query strings use the kebab-case `ApiEnums` names, exact only.
- Affected technologies are an owned table with a foreign key to `Technologies.Slug` (an alternate
  key, so no extra unique index). Source links are a JSON complex collection. Tags and CVE ids are `text[]`.
- `status` filter: validation first (400), then anonymous 401, non-staff 403; staff lists get
  `Cache-Control: private, no-store`.
- List ETag: weak, from path and query, newest `updatedAt` and count, computed in one grouped query
  before the page is read. Item ETag: strong `xmin`. If-None-Match uses weak comparison.
- The slug route has a regex constraint needing a letter, so it never clashes with the future `/news/{id}` write routes.

## Tried and rejected

- Naming the helper `ApiEnum`: CA1711 fails the build.
- Keeping HtmlSanitizer's default attributes: it strips `class` and loses `language-*` on code blocks.
- `dotnet ef migrations remove` without a database: it tries to connect; delete the files and
  restore the snapshot from git instead.
- Editing C# files with Python in text mode on Windows: it writes CRLF and fails format:check.
