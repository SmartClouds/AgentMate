## Decisions

- Playwright's web server is `bun run build && bun run start`, so e2e also proves the built server
  runs under bun. A Sentry-enabled build was also smoke-tested under bun (200 and 404).
- Sentry is in the bundles only when `PUBLIC_SENTRY_DSN` is set at build time; the server init reads
  `process.env` at runtime first. Source maps upload only with `SENTRY_AUTH_TOKEN`.
- `<html class="dark">` is server-rendered; an inline head script (`themeInitScript`) applies the
  stored or system theme before paint. Chromium reports light for an emulated `no-preference`, so
  the Dark default is tested with JavaScript off.
- Bricolage Grotesque's `@font-face` is declared in global.css with `font-display: optional`;
  Inter and JetBrains Mono use Fontsource's CSS (swap). Inter and Bricolage Latin are preloaded.
- Token test compares app Light (`:root, .theme-light`) and Dark (`.dark`, inheriting `--radius`)
  and the `@theme inline` block; site-only tokens allowed: `--glow`, `--grid-line`, `--severity-*`.
- Vitest (named by the spec) and Vite (comes with Astro) have Chinese maintainers among VoidZero;
  kept because the spec requires them, recorded in the commit message.

## Tried and rejected

- An e2e test with `colorScheme: 'no-preference'`: Chromium resolves it as light, so it can't show
  the Dark default.
- `execFileSync('pnpm', ..., { shell: true })` in the workspace test: Node DEP0190 warning; uses
  `execSync` with a string instead.
