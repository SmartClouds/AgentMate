## Decisions

- One `Releases` row per tag (unique `TagName`); the latest is the newest `FetchedAt`. A 304 changes nothing.
- macOS with no arch gives arm64, universal, x64; an asked arch falls back only to universal.
  Windows and Linux use the asked arch, x64 by default.
- `/downloads`: unknown platform, arch or kind is a 404. `/assets`: unknown values are 400 `validation-failed`.
- Endpoints re-check stored assets with `DesktopAssets.Classify`. Assets not `uploaded` are left out;
  `sha256` only from a 64-hex `sha256:` digest.
- The job catches HTTP, JSON and timeout failures, reports to Sentry, logs a warning and returns (no retry).
