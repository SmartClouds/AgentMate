## Purpose

If-Match, validation, audit entries, and a `news-publish` Hangfire job that publishes scheduled items.

## Decisions

- The endpoints read the body as `JsonNode` and deserialize it themselves, so JSON errors become 400
  `validation-failed` keyed by path. PATCH merges into the stored item's write DTO and validates the whole result.
- The experimental validation APIs (ASP0029) are suppressed with `#pragma` at the attribute and in `RequestBodies.ValidateAsync` only.
- A write that changes nothing saves nothing and writes no audit entry; archiving an archived item is 204 with no entry.
- Digits-only paths under `/news/` are now the id route (staff only), so the T006 read test's `12345` slug case was removed.
- `WebsiteApiFactory.Dispose` clears its database's Npgsql pool: per-test databases left idle
  connections open and a full run hit "too many clients" (the T006 flakiness note).
- Idempotency-Key and API-client auth stay for T008.

- Comparing `response.Headers.CacheControl?.ToString()` in tests: .NET reorders it to "no-store, private"; read the raw header.
