## Decisions

- The site imports the app's own `parse.ts`; nothing is copied. Leg 1 decisions stand (CRLF
  normalized, unused filter rules fail a unit test, heading ids follow the app's section ids,
  feature link and screenshot mapping rules, meta description rules).
- Keywords reach Pagefind through a hidden `data-pagefind-index-attrs` div; the e2e test proves it.
- The build spec reads `dist/client` lazily inside the tests, because Playwright loads spec files
  before the web server step has built.
- The no-match search test uses `qwxzv`: Pagefind fuzzy-matched `zzqqxx` to an article.
