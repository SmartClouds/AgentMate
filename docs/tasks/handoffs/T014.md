## Decisions

- Leg 1 and 2 decisions stand (inline SVG fallback, scene in a module worker, GPU-off flags for
  the no-WebGL e2e, lighthouserc on `localhost:4321`, mobile).
- No React on the home page: a React island hydrating before FCP put its 208 KB runtime into
  Lighthouse's simulated LCP. The hero keeps client:visible behaviour without a framework.
- The preview compresses because production does; an uncompressed preview counted about 220 KiB
  the real site never sends.
- Best practices is 0.96 only because of `image-size-responsive`; the budget is 0.95.

## Tried and rejected

- Leg 1 and 2 items (Float32BufferAttribute copy, fog on the star, smooth scroll, worker start
  alone).
- `client:idle` for the toggle and the hero: locally the page loads in about 100 ms, so idle fires
  before FCP and React stayed in the LCP graph (LCP 3.9 s).
- `Bun.serve` for the proxy: the project has no Bun types, so `astro check` failed.
