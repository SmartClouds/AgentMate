## Decisions

- Pictures are taken with CDP `Page.captureScreenshot` (clip scale = 2 / devicePixelRatio).
  Playwright's `page.screenshot` of the Electron page came out at 1600x1000. The spec asserts
  the PNG size.
- Dashboard: demo IP 203.0.113.24 (Netherlands) through `RUNOVA_E2E_IP_GEO`. `pingMethod: 'http'`
  is set because this network drops ICMP, which made Network Status show "offline".
- Skills shot is the marketplace Directory page (button shows Global Skills 4). Skill Security
  opens the Global Skills dialog and checks `store-setup`. MCP is filtered to Installed (4).
- storefront is seeded with a standing prompt and notes so Project detail isn't empty.
- `capture()` hides toasts, stops animations and the caret with a style tag, and moves the
  mouse to (1000, 70) so no hover highlight shows.
- Leg 2 and 3 decisions stand (subst demo drive, theme via the Settings UI, totals.ts diff).
