## Decisions

- **E40W, not E40**: E40 is reCAPTCHA keys. T028's "rows E40 to E42" means E40W, E41, E42.
- **Signing key = SHA-256 of the secret**, sealed with Data Protection (keys in PostgreSQL).
- **Forbidden list** is the fenced `forbidden` block in 40-website.md: phrases up to the first `#`
  line, then the help filter rules for `remote.md`. "Mobile app" alone is not forbidden, so the
  Android emulator example in `projects.md` stays.
- Fonts: Inter Variable, Bricolage Grotesque Variable (display), JetBrains Mono Variable (mono).
  Severity colors in design.md are checked for AA on background, card and muted in both themes.
- Features: 12 entries in 40-website.md, adding `projects` (a README group T015 did not name) and
  `more` for "The rest". The news matcher lives in `apps/desktop/src/main/news/match.ts`.
- The check script and this handoff are not committed (task docs only); the task file is Runova's.

- Putting the news matcher in packages/core: T023 scopes it to main/news.
